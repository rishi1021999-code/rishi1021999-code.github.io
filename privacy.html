Privacy Policy - Margin Walk Studio

Last updated: 24 October 2026

Margin Walk Studio ("the app") is a private tool used only by the owner of the YouTube channel Margin Walk to manage that channel. Home page.

Google user data the app accesses

When the channel owner signs in with Google, the app requests these permissions, for the owner's own channel only:

  • youtube.upload - upload the channel's own videos (as private, optionally with a scheduled release time).
  • youtube.force-ssl - manage the channel's own videos, captions, thumbnails and playlists, and read the channel's own video list.
  • yt-analytics.readonly - read the channel's own YouTube Analytics reports.

How the data is used

The data is used only to upload and manage the channel's own videos and to check their status and performance. It is not used for advertising, not sold, and not used to build profiles of anyone.

Storage and protection

The Google sign-in token is stored only on the owner's own computer, in a file readable only by the owner's account. The token is never written to logs. Information about the channel's own videos (video IDs, titles, upload and privacy status, and view and analytics figures) is stored on that same computer in a local database, local log files and local copies of that database. Nothing is stored on any server operated by the app; the app has no server.

Sharing

Google user data is not shared with, transferred to, or sold to any third party. The app uses an AI language model (Google Gemini, reached through a gateway running on the owner's computer) to help draft video scripts and titles from public company filings. No data obtained from Google or YouTube APIs is included in those requests.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube API Services Terms of Service; see also the Google Privacy Policy.

Retention and deletion

Data stays on the owner's computer until the owner deletes it; there is no automatic expiry. Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token file, database, database copies and log files removes all stored data.
